# SaaS Ecommerce Platform

Full-stack SaaS e-commerce application built with:

- React + Vite + TypeScript
- Tailwind CSS
- PHP (API)
- MySQL

## Features
- Authentication
- Products & orders CRUD
- Admin dashboard
- SaaS-ready architecture

## Tech Stack
Frontend: React, Vite, Tailwind  
Backend: PHP  
Database: MySQL

## Setup
1. Clone repo
2. `npm install`
3. Create `.env`
4. Run frontend & backend
